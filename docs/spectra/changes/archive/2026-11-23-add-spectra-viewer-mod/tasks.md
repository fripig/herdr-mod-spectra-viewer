## 1. Pure logic (mods/spectra-viewer/logic.js)

- [x] 1.1 Spec directory from configuration: `resolveSpecDir` returns `spec_dir` from `.spectra.yaml` or `openspec`, warning on absolute, escaping, empty or non-scalar values (Spec dir decided by configuration only). Verified by `npm test` "spec_dir from .spectra.yaml, else openspec" and "an unusable spec_dir warns and falls back".
- [x] 1.2 Change details: `parseTaskProgress` counts checkboxes outside fenced code, `deriveStatus` gives draft / notStarted / inProgress / complete, `parseMetadata` gives the created date and the proposer name without the address. Verified by `npm test` "task progress ignores fenced checkboxes", "status from progress" and "metadata: created date and proposer name without the address".
- [x] 1.3 Three groups of changes from one shell script scans everything: `SCAN_SCRIPT` plus `parseScan` list Active (skipping `archive`), Archived and Parked change folders with artifacts in proposal/design/tasks-first order, mtimes, progress and metadata, and report an unfinished scan. Verified by `npm test` "scan lists active, archived and parked changes" (real fixture folder) and "scan without a parked folder or changes folder".
- [x] 1.4 Sorting and filtering: `sortChanges` (modified, created, name; unknown dates last), `filterChanges` (case-insensitive name plus proposer), `proposers` and `groupCount` (`shown/total` while filtering). Verified by `npm test` "sorting: newest first, unknown dates last, ties by name" and "filter by name (case-insensitive) and author".
- [x] 1.5 Typing commands with hc keys and target terminal: `keyNames` maps a command line to one `hc keys` name per character and refuses unsafe characters; `targetTerminal` picks the focused terminal pane, else the tab's first agent, else its first terminal. Verified by `npm test` "command line as hc key names" and "target terminal: focused terminal, else the tab's agent, else its terminal".
- [x] 1.6 Panel placement helpers: `withSpectraPanel`, `panelToggle`, `panelOn`, `panelHidden`, `canDock`, `WINDOW` and `viewerWindow` (document viewer as a keyed window). Verified by `npm test` "panel button and window commands".
- [x] 1.7 Interface language strings in mods/spectra-viewer/i18n.js: `en` and `zh-TW` with the same keys, `pickLanguage`, `languageFromDetection`, `chooseLanguage`, `t`. Verified by `npm test` "languages".

## 2. The View (mods/spectra-viewer/main.js)

- [x] 2.1 Project follows the focused folder: `location()` and `resolveProject` use the focused pane folder and git's common dir (parked folder from git's common dir), keep the project while a mod pane is focused, and rescan only when the root or machine changes. Verified manually in herdr-app: the panel showed this repo's `docs/spectra` changes and still did after a document pane took focus.
- [x] 2.2 Staying current: scans on start, every 30 seconds, on the refresh button and on `watchFolder` events for the local spec and parked folders, with one queued rescan while busy. Verified manually: a new fixture change folder and a ticked task appeared without clicking.
- [x] 2.3 Change panel rendering: title row, refresh, filter box, sort chips, author chips, the three groups with counts, change rows with proposer and colored progress, and the expanded command / copy / artifact rows. Verified by `herdr-app check ~/.config/herdr-app/mods/spectra-viewer` printing `check passed` and a screenshot of the floating window (preview.png).
- [x] 2.4 Viewing artifacts: clicking an artifact opens the `spectra-viewer-doc` window rendered with `TextView.markdown`, with reload, move-to-pane and ✕, reloading on file changes and showing "<file> is gone." for a missing file. Verified manually by opening the viewer as a pane with `herdr-app do pane.split` on a fixture `proposal.md` and seeing the rendered headings, list and code block.
- [ ] 2.5 Typing a Spectra command, fallback to the clipboard and copying the change name, clicked from the panel: `apply` leaves `/spectra-apply <name>` unsubmitted at a focused Claude Code prompt and focuses it; with no terminal the line is copied with a toast; copy name puts only the name on the clipboard. Verify manually by clicking each button in herdr-app (the `hc keys` mechanism itself was confirmed on a scratch terminal, which printed the typed line only after a separate Enter).
- [ ] 2.6 Interface language switching from the title-bar chip updates every copy, including the filter placeholder. Verify manually by clicking EN / 中 in herdr-app.
